# RhythmSense

  RhythmSense: Deep Learning-Based Heart Disease Detection from ECG Signals

# Overview

 RhythmSense is an AI-powered heart disease detection system built using deep learning on raw ECG signals. The project uses the [PTB-XL dataset](https://physionet.org/content/ptb-xl/1.0.1/), a large publicly available       collection of 12-lead ECG recordings, to train models capable of identifying cardiac conditions such as:

  - Myocardial Infarction (MI)
  - Atrial Fibrillation (AF)
  - Conduction Disturbances (CD)
  - ST/T Wave Changes (STTC)
  - Left Ventricular Hypertrophy (HYP)
  - Normal ECG

# Project Goal

  To build a robust and explainable deep learning model that performs **multi-label classification** of heart diseases directly from raw ECG waveforms. The project aims to help in early screening, especially in remote or     resource-limited settings.


# Dataset 

  - 📈 21,837 10-second 12-lead ECG recordings  
  - 🕓 Sample rate: 500 Hz (high-res) and 100 Hz (low-res)
  - 🧾 Multi-label diagnoses with 71 SCP codes
